# 原文勘误与复现决策

基准为用户提供的《neurodiffeq Documentation》，封面 2023-04-03，共 138 个 PDF 页面。下表使用 **PDF 页码**（印刷页码通常减 4）。未将当前在线文档取代历史基准。

|位置|问题或歧义|判断依据|本项目处理|
|---|---|---|---|

|§1.4.2，PDF 10–11|Poisson 仅给方程、解析解及图，无网络和轮数|自动微分检验 `Δ[x(1-x)y(1-y)e^(x-y)]` 与正文右端一致|方程不改；补充 32×32 网络、32×32 采样、Adam、2000 轮，配置明确标为项目补全。正文约 6e-5 的图示误差单独比较，不宣称复现到该精度|
|§2.2.2，PDF 19；§3.1，PDF 31|默认网络被分别描述为一层和两层；训练点数出现“16点/32等距点”矛盾|安装的 0.7.0 实际默认网络为 (32,32)，Solver1D 默认训练生成器 size=32|全部显式配置，使用两层各32单元及32点；不依赖版本默认值|

|§2.4，PDF 28|`CustomBoundaryCondition.in_domain` 使用插值长度因子的符号，并非精确多边形包含判断|检查 0.7.0 `CustomBoundaryCondition.in_domain` 源码|训练/验证使用原文插值域与严格六角星的交集；测试只用严格六角星内的独立随机点。保存实际训练点，几何偏差在报告中量化。这是显式修正|

本项目未发现需要改动 Poisson 强迫项、Laplace 解析解或星形 PDE 右端的数学错误：都有自动微分代入测试。对没有原文种子、机器、停止点权重的实验，不能承诺逐像素重现原图。

本项目自身的收尾修正：Matplotlib Path 的负半径需配合逆时针顶点才能表示向内缩；将原文顺时针顶点在包含判定时反转，并增加120个控制点都不属于“严格内部”的测试。原文32×32训练及100×100验证网格、独立随机测试点的选择不变；仅改变恰在边上的网格点归类。边界误差仍单独统计，不用这一修正改善训练指标。

§3.1.1本身只定义振子方程与条件，`solver_config`为使该片段能独立训练而补充默认网络及1000轮基线，不能称为原文独立给定的训练任务。`hard_soft`同样是明确新增的1000轮对照。

依赖兼容性补充：纯CPU新环境中最新pyparsing会触发Matplotlib3.9.2的大量弃用警告；锁定pyparsing3.1.4并重新通过测试。没有用全局忽略警告掩盖接口问题。

`大创1.py` 在交付时若仍未提供，其许可证和内容均不得猜测。工作目录的 `test.py` 是一个旧 `solve` 指数衰减脚本，与本项目 `decay` 对应；它不能被假定为同一个参考文件，不复制进入仓库。
