# 训练前确定的验证协议

各运行开始前将完整配置和验收线写入 `config.json`。固定阈值在首次训练前写入 `tools/create_catalog.py`，不按结果下调。所有值是无量纲示例中的绝对或整体相对量；并不代表物理工程容差。

|问题|最大解误差|整体相对 L2|残差 RMSE|初始/边界最大误差|
|---|---:|---:|---:|---:|
|指数、振子、圆、LV、Laplace、热方程|0.03|0.02|0.03|1e-8|
|Poisson（解幅值约0.06）|0.002|0.02|0.03|1e-8|
|星形PDE（插值边界）|0.04|0.05|0.1|0.01|
|新增硬/软约束对照|0.03|0.02|0.03|0.01|

必须同时通过上述各项；RMSE也报告，但不另设一个重复的阈值。Poisson图示约6e-5是原文展示结果，不是原文承诺的保证。报告另外比较是否接近这一数值，不能只通过本项目较宽的入门标准就声称重现了原图精度。

默认CPU、float64、单PyTorch线程。每个实验记录seed、版本、网络、优化器、采样、训练轮数、实际时间。reproduction保留原文明确指定的轮数；默认轮数和配置歧义见勘误。第1章缺少训练程序的内容明确区分“公式复现”和“补全实现”。

测试集用独立 NumPy Generator，种子20230403，与训练/验证生成器不同。在1D上随机抽样并排序；规则PDE在矩形内均匀抽样；星形PDE用严格六角星内拒绝采样。完整实验2048点，smoke256点。边界随机流20230404，与内部测试分开。训练、验证和测试点来自不同生成机制；连续随机点不会系统性重用训练网格。

规则区域硬条件测试初值/四条边；热方程分别测试初值与两端x导数。星形控制点每边10个不重复起点，共120个（原文每边11点含终点，循环去重等价）；测试每边53个半步偏移点，共636个，避开训练控制点。图只显示合法域，预测和参考热图共享色标。

参考：解析解先通过自动微分代入和边界测试；LV使用DOP853双容差比较，差异须小于1e-7，随后使用更严格容差的一次积分作为数值参考。LV还检查不变量。没有把数值积分的浮点输出叫作精确解。

每100轮和运行结束保存一次检查点、历史损失和进度。`--resume` 只跳过已完成的相同配置，包括完整训练但未达标的结果；它不会把失败实验偷偷改配置再训练。`--resume-from` 从指定的本地检查点继续至原定总轮数，另开目录并记录来源。旧接口例因不支持同样的回调路径，只在结束保存；意外中断时可重跑该小例。warmup阶段中断可从对应阶段的显式记录分析或重跑迁移示例。

数值未达标不是程序崩溃：CLI在训练与文件输出完成时正常退出，数值状态由 `numerical_pass` 表示。CI验证数学正确性和流程完整，不要求2轮训练达到数值阈值，也不重复完整训练。
