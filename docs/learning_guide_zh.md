# 从第一条微分方程开始

建议先运行指数衰减 smoke，再做 reproduction，最后打开其 `solution.png`、`loss.png` 和 `metrics.json`。第一次先不修改任何参数。

## 1. 网络如何表示解

普通回归给网络许多输入和正确答案；这里通常只给方程和初始/边界条件。网络输入时间 t，输出一个数 Nθ(t)。参数 θ 是各层的权重和偏置。它是一个可以在任意时间求值的函数，不只是一个离散表格。

指数衰减要求 u′+u=0、u(0)=1。我们实际使用 `uθ(t)=1+(1-exp(-t))*Nθ(t)`。因此网络原始输出与物理解不是同一个东西。把 t=0 代入，第二项消失，初值自动成立。此处网络不是直接被设置为解析解 exp(-t)，仍然必须通过训练满足方程。

第一个完整例子代码由 `examples/chapter2/decay.py` 进入，共享数学定义在 `src/ndeq_examples/math.py`，条件与求解器构造在 `models.py`。每次运行生成独立目录，不会覆盖上一次曲线。

## 2. 自动微分如何工作

考虑 y=t³+sin(t)，其导数应为 3t²+cos(t)。PyTorch记录加法、乘法、正弦等运算的计算图，再用链式法则求导。它不需要用两个相邻点的差商来近似导数，也不是把整个表达式转成符号公式再化简。

`torch.tensor(..., requires_grad=True)` 告诉框架需要跟踪输入；`diff(y,t)` 计算一阶导，`diff(y,t,order=2)` 计算二阶导。输入保持 `(点数,1)`，不要提前 `.detach()` 或转换为 NumPy，否则会切断计算图。求 PDE 残差时也不能随意放进 `torch.no_grad()`。

训练还需要另一种导数：损失对网络权重的导数。第一种导数是对时间/空间；第二种导数帮助优化器改进网络。`autodiff` 示例和数学测试分别检查导数值。

## 3. 残差损失与条件

把预测函数代入方程，得到残差 r(t)=uθ′(t)+uθ(t)。一批采样点上的平方残差平均值就是常用训练损失。优化器调整 θ，使它变小。

残差不等于解误差。`2*exp(-t)` 的残差也为零，却不满足 u(0)=1，解误差很大。运行 `residual_demo` 可以看到这个反例。残差需要方程；解误差需要解析解或可信的数值参考。

硬约束将条件写进函数结构。软约束直接用 Nθ(t) 表示解，在损失中增加 `λ*(Nθ(0)-1)²`。软约束通常只近似满足初值，而且 λ 改变了两个目标之间的权重。项目新增的 `hard_soft` 对照固定相同网络、采样、轮数和三个种子，比较硬约束与 λ=1 的惩罚项；它不是文档中已运行的实验，也不证明哪一种在所有问题上更好。

非零边界常用 `g(x)+A(x)Nθ(x)`：g负责边界值，A在边界为零。Neumann条件约束导数而非函数值。本项目热方程在 x=0、2 上规定非零导数，不能改成“端点温度为0”而说问题相同。

## 4. ODE、方程组和 PDE

ODE只有一个自变量。例如振子的 u(t)，但可以有二阶导数。把速度写成 v=u′，可转换为两个一阶方程 `u′=v, v′=-u`，未知函数变为两个，网络和条件也各有两个。

PDE含多个自变量。例如热方程 u(x,t) 同时依赖位置与时间；虽然只沿一根杆传热，网络仍有两个输入。Laplace和Poisson例中两个输入是x、y。星形区域还需判断点是否在有效区域内，不能在包围它的整个矩形上统计误差。

振子还有能量 `E=(u²+v²)/2`。真实解能量为1/2，观察能量偏差可识别振幅衰减。Lotka–Volterra的闭合相轨迹同样能揭示长期相位和幅度误差，仅看几条数值可能漏掉这些问题。

## 5. 与传统数值方法比较

SciPy的 `solve_ivp` 从初值出发一步步积分，容差控制局部误差，速度通常很快。神经网络方法把求解变成非凸优化，要选择网络、采样、优化器和训练轮数。网络能给出连续表示并利用自动微分，但不意味着一定比传统方法更准确、更快。

项目中的Lotka–Volterra使用DOP853作为数值参考，并将 `(rtol,atol)=(1e-9,1e-11)` 与 `(1e-11,1e-13)` 对照。两次积分接近可增强可信度，但仍称“数值参考解”，不称“精确解”。有解析解的PDE直接用解析解，不额外引入不匹配边界条件的差分模型。

## 6. 为什么训练损失小仍可能误差大

训练只约束采样点，点间可能出现误差；初始/边界条件可能没满足；导数误差沿长时间积累会造成相位漂移；不同方程项的尺度会改变损失大小。星形域中，控制点之间的插值误差也不会因为控制点本身吻合而自动消失。

验证集用于选择 `best_nets`，不能再当作独立测试集。项目另用固定随机流产生测试点，训练种子不同也在同一测试点集上比较。有零点的振子不使用逐点相对误差，而用整体相对L2范数 `||预测-参考||₂/||参考||₂`。

## 7. 如何阅读一次结果

先打开 `config.json` 看问题与训练轮数，再看 `status.json` 判断模式和完成情况，最后看 `metrics.json` 的 `acceptance_checks`。某一项False就没有达到项目数值标准。smoke即使偶然误差很小，也不会被标成数值复现通过。

`history.json` 是每轮的训练/验证目标；`test_data.npz` 包含测试坐标、预测、参考、方程残差、条件误差；`plot_grid.npz` 是PDE作图网格。可以用 NumPy 读取：

```python
import numpy as np
data = np.load("results/selected/某个运行目录/test_data.npz")
print(data.files)
print(data["points"].shape)
```
